# Data Analytics & Machine Learning Portfolio

Repositorio que reúne proyectos de análisis de datos, machine learning, SQL y business intelligence. Cada carpeta contiene un proyecto independiente, con su código, documentación y resultados disponibles.

## Proyectos

### 1. Microsoft Malware Prediction

Proyecto de clasificación supervisada orientado a la predicción de malware. Incluye preparación de datos, entrenamiento y comparación de modelos, evaluación de métricas e interpretación de resultados.

**Áreas:** Python, machine learning, clasificación.

[Ver proyecto](./01_malware_prediction/)

### 2. Retail Sales Forecasting

Análisis de ventas minoristas para estudiar tendencias y estacionalidad, así como comparar enfoques de predicción de series temporales.

**Áreas:** análisis temporal, forecasting, Python.

[Ver proyecto](./02_retail_sales_forecasting/)

### 3. Madrid Real Estate Analytics

Análisis de información inmobiliaria de Madrid mediante SQL, utilizando filtros, agregaciones, subconsultas, joins y vistas para responder preguntas sobre el mercado.

**Áreas:** SQL, consultas analíticas, sector inmobiliario.

[Ver proyecto](./03_madrid_real_estate/)

### 4. Chargeback Analytics

Proyecto de visualización de indicadores relacionados con contracargos mediante un dashboard en Looker Studio, con KPIs, filtros y gráficos para facilitar la exploración de resultados.

**Áreas:** business intelligence, Looker Studio, dashboards.

[Ver proyecto](./04_chargeback_analytics/)

### 5. European Weightlifting Analytics

Análisis de datos de halterofilia europea mediante Python, incluyendo recopilación de información por web scraping, limpieza, transformación y análisis exploratorio.

**Áreas:** Python, web scraping, EDA.

[Ver proyecto](./05_european_weightlifting_analytics/)
